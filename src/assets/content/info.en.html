FreeClock

Open source smart clock

FreeClock is an open source smart LED matrix clock, easy to assemble, with a 3D-printable shell and a mobile app for management. It communicates via Bluetooth Low Energy (BLE) and can be fully configured from your smartphone.

Key features

  • Guided pairing with 6-digit PIN
  • Wi-Fi, timezone, display and brightness configuration
  • Weather, news, quotes, quiz and jukebox modules
  • OTA firmware update
  • Push notifications via Firebase Cloud Messaging
  • Multi-language support (Italian and English)

Getting started

Tap the + button on the Devices screen to start the pairing procedure. Follow the guided steps to connect the device to your Wi-Fi network and configure the timezone.

Settings

Once paired, tap the device in the list to connect and access its settings. Every change must be sent to the device using the Send to device button.

Weather

To display weather information you need an OpenWeatherMap API key (free account) and the city ID you want to use.
